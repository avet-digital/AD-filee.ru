## Установка на Mac

Нужна macOS 14 или новее. Выберите архив под ваш процессор:

| Ваш Mac | Файл |
|---|---|
| Intel (Core i5 / i7 / i9) | `Filee-…-osx-x64.tar.gz` |
| Apple M1 / M2 / M3 / M4 | `Filee-…-osx-arm64.tar.gz` |

1. Скачайте архив со страницы [Releases](https://github.com/avet-digital/filee-ru/releases/latest) и откройте его двойным щелчком.
2. Откройте **Терминал**, перетащите в него файл `install.sh` из распакованной папки и нажмите <kbd>Enter</kbd>.
   Программа скопируется в папку «Программы» в вашей домашней папке (`~/Applications`).
3. Запустите **Filee**. Если macOS сообщит, что разработчик не проверен, откройте
   **Системные настройки → Конфиденциальность и безопасность** и нажмите **«Всё равно открыть»**.
4. Разрешите Filee доступ в **Универсальном доступе** (для жестов) и к **Finder** в разделе «Автоматизация», когда программа попросит.

Удаление — файл `uninstall.sh` из той же папки. Настройки и результаты конвертации при этом сохраняются.
