## Замечания

| ID | Уровень | Описание | Решение |
|---|---|---|---|
| R-1 | Низкий | `SetupPayload.cs:197` (установщик Windows) не проверяет, что путь файла из манифеста остаётся в папке установки. Манифест — часть нашего же установщика, файлы сверяются по SHA-256 | Рекомендация: добавить проверку при работе над Windows-сборкой |

Подписи Apple Developer ID нет — `codesign --verify` подтверждает целостность, но не издателя | 2FA на GitHub `avet-digital` (обязательно); позже — Developer ID и сертификат Windows |
| R-3 | Инфо | Программа обращается к сети: GitHub API (проверка обновлений), сайты движков (по выбору пользователя) | Указать в описании программы / политике конфиденциальности |
| R-4 | Низкий | CI автора (semgrep OWASP в GitHub Actions): `portable.yml:62` — `curl https://sh.rustup.rs \| sh` (только Linux-пакеты, мы их не выпускаем); `release.yml:39,101` — `${{ github.ref_name }}` / `${{ steps.version.outputs.value }}` прямо в `run:` (сценарий только ручной, теги ставим мы) | При настройке Windows-сборки передавать значения через `env:`; Linux-сборку отключить или закрепить rustup по хэшу |
